# 多面向量化分析法（Multi-Dimensional Analysis）

## When to Use / 何時使用
當用戶要求分析某事物的「適合性／資格／優劣」，且希望報告**公平、客觀、多角度**時（例：選文是否入課本、政策好不好、方案優劣）。
當用戶要求分析某事物的「適合性／資格／優劣」，且希望報告**公平、客觀、多角度**時（例：選文是否入課本、政策好不好、方案優劣）。

## 核心原則
1. **先界定標準**：在評析前，先把「好壞的維度」明確定義出來（如依課綱五項能力），讓評分有據可依。
2. **量化驗證**：能用數字說明的就計數、算比例（關鍵詞頻率、占比、分界定位），避免純主觀形容。
3. **區分兩類問題**：「品質問題」vs「尺度/形式問題」；「核心命題」vs「配角」。這能避免以偏概全。
4. **誠實標條件**：結論要寫出「符合，但有條件」，並指出適用範圍與限制（如「入口型教材 ≠ 終極訓練」）。
5. **正反對照**：列出支持方與反方的論點，做成對照表，讓讀者自行判斷。

## 執行步驟
1. **收集原文/原始資料**：先抓全文或一手來源，別只靠二手報導。
2. **量化計數**：用 terminal + grep/python 統計關鍵詞出現次數、占比、主題分界位置。
3. **建立維度矩陣**：每個面向給分（★），附具體證據（優點+弱點）。
4. **正反對照表**：支持方 vs 反方，各列論點。
5. **綜合結論**：區分「核心」與「配角」，標出「符合但有條件」。
6. **一句話總結**：用引用塊（>）給出一句可記憶的核心結論。

## 常用維度（依情境選用）
- 文本評析：文學性、語言可讀性、結構、修辭、主題契合度
- 教育應用：符合課綱、心理發展適切性、思辨訓練、人文素養
- 實務評估：可行性、成本、風險、配套需求

## 報告格式（用戶偏好）
- 參考資料集中放**最後一章**，分類清晰（文本原典／支持方／反方／背景），附原始連結。
- 每章有標題、表格、一句話總結引用塊。
- 目錄與章節編號要一致（新增章節時同步更新）。

## 範例：〈泳褲〉選文評析的量化結果
| 主題 | 關鍵詞 | 次數 | 占比(3449字) |
|------|--------|------|-------------|
| 身體焦慮 | 焦虑/恐懼/陰影/創傷/怕 | 23 | ≈0.7% |
| 同儕目光 | 大家/男生/女生/被看/被小看 | 31 | ≈0.9% |
| 文化差異 | 德/美/台/FKK/夏令營 | 29 | ≈0.8% |
| 自我接納 | 喜歡自己/舒坦/自在/和解 | 12 | ≈0.3% |

## 常見陷阱
- 只憑印象給分，沒有計數或原文佐證。
- 把「尺度爭議」誤當「品質問題」（如雞雞論戰）。
- 結論非黑即白，不標出適用條件與限制。
- 參考資料散落在各處，沒集中放最後。
