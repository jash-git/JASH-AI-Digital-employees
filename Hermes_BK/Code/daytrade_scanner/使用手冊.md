# 隔天當沖選股掃描器 — 簡易使用手冊

## 這是什麼？
每日收盤後執行，自動掃出「隔日開盤有機會成為當沖標的」的股票，並附上：
- 進場點（觸發價）
- 停損點
- 停利點（TP1 / TP2）
- 做多 / 觀望方向
- 風險報酬比（R:R）

資料來源：
- **Yahoo Finance**（開高低收、成交量）—— v1 技術面唯一來源。
- **TWSE 交易所 API**（T86 三大法人買賣超，可回溯歷史日期）—— v2 籌碼層來源。
⚠️ 部分 TWSE 端點在本環境被反爬擋住（見末頁「參考網址」）。

---

## 一、第一次使用（只需做一次）

```bash
cd /home/vblinux/daytrade_scanner
python3 scanner.py --help
```

確認指令能跑、沒有網路錯誤即可。

## 二、每天收盤後怎麼用

**最簡單——直接執行：**
```bash
cd /home/vblinux/daytrade_scanner
bash run.sh
```
預設輸出分數最高的 12 檔，CSV 自動存到 `results/scan_今天日期.csv`。

**自訂筆數：**
```bash
bash run.sh --top 8
```

**自訂門檻（只挑分數夠高的）：**
```bash
bash run.sh --min-score 50
```

**完整選項一次給：**
```bash
python3 scanner.py --top 10 --min-score 48 --out-csv /tmp/我的清單.csv
```

## 三、怎麼讀結果

### 快速表格（最上面那張）
```
代號     名稱        收盤    分      進場       停損      TP1      TP2    R:R
2377   台積電      155.0   60做多   155.5    153.1    158.9    161.3    1.5
```
- **分**：0–100，越高越符合「強勢當沖標的」。
- **方向**：`做多`＝動能延續；`觀望(開高走低風險)`＝乖離過大，建議別追。
- **進場**：隔日股價突破這個價才進（突破策略）。
- **停損**：跌破就賣，控制虧損。
- **TP1 / TP2**：兩個停利目標。
- **R:R**：風險報酬比，≥1.5 才算值得做。

### 詳細說明（表格下面）
每檔會寫明：收盤、量倍、均線位置、進場/停損百分比、停利位、以及「籌碼面需人工確認」的檢查項目。

## 四、停損 / 停利 / 進場——白話說明（重要）

用一個例子就懂。假設今天收盤後選到**台積電**，收盤價 **150 元**。

### ① 進場價（明天幾塊買進去）
- 如果明天開盤「衝破昨天最高點」就買 → 大約 **150.5 元**買進
- （若當日已突破前日高，會改以「收盤 × 1.003」追單，避免錯估）

### ② 停損（賠到多少就跑，控制虧損）
規則：最多只准賠收盤價的 **0.8%～1.5%**。
- 150 元的約 1% ≈ **1.5 元**
- 所以「停損價」= 150.5 − 1.5 = **149 元**
- 明天如果跌到 149，就賣掉，**最多賠 1.5 元/股**

### ③ 停利（賺到多少就收手）
用「你冒的險」來算目標。你冒險賠 1.5 元，那就：
- **TP1（第一檔獲利）** = 進場 + 1.5 × 1.5 ≈ **152.8 元**（賺約 2.3 元）
- **TP2（第二檔獲利）** = 進場 + 1.5 × 2.5 ≈ **154.3 元**（賺約 3.8 元）

### 一句話總結

| | 規則 |
|---|---|
| 買進 | 明天衝破昨天最高就追單買 |
| 賠太多就跑 | 最多賠 0.8%～1.5%（約 1.5 元） |
| 小賺就走 | 賺到冒險的 1.5 倍 → TP1 |
| 大賺就走 | 賺到冒險的 2.5 倍 → TP2 |

**核心精神：「虧要限得住（最多賠 1.5%），賺要放得開（賺 1.5～2.5 倍）」**，這樣即使贏一半、輸一半，整體還是會賺。

### 技術細節（想深入再看）
- **停損** = `max(收盤 × 0.8%, ATR×14 × 0.6)`，上限 1.5%（`THRESHOLDS` in scanner.py:58-62）。
- **TP1/TP2** = 進場 ± risk × (1.5 / 2.5)，risk = 進場 − 停損。
- 完整邏輯在 `scanner.py` 的 `build_trade_plan()`（第 231 行起）。

## 五、v2 版本：加碼「三大法人籌碼層」

**v1 只用技術面**（成交量、均線、波段形態）。**v2 在 v1 之上疊加 TWSE 三大法人買賣超**，讓選股多一層「主力進場動能」判斷。

### 怎麼跑
```bash
cd /home/vblinux/daytrade_scanner

# 即時選股（今天收盤後 → 明天開盤標的）
python3 scanner_v2.py --top 10 --min-score 45

# 回溯測試（看歷史表現，1～9 月）
python3 backtest_v2.py --start-month 1 --end-month 9
```

### v2 多了什麼
- **籌碼加分**：外資當日淨買超 +15 分、投信買超 +10 分（加在 v1 分數之上，總分上限仍 100）。
- **方向提示**：表格會顯示「看多（外資淨超 XX 萬股）」或「看空風險」。
- **做空估值**：外資大賣超時，提供反向做空的進場/停利/停損估算。

### v2 資料來源
- T86 端點抓三大法人買賣超（逐檔、可回溯歷史日期）。
- Yahoo Finance 仍負責技術面（與 v1 完全相同）。

### ⚠️ v1 vs v2 差異（誠實說明）
回溯測試結果見 `results/v1_vs_v2_比較報告.md`。重點：v2 的籌碼層目前是「加分制」——只在 stock **已經通過技術面門檻後**才加分，所以選股清單與 v1 相同。**若要讓籌碼真正影響入選**（例如「外資買超 + score≥40」才入選），需再調整邏輯。


- 想拿掉 → 刪掉那一行。

改完存檔，下次執行自動生效。**不用重裝、不用重設。**

## 八、常見問題

**Q：跑完顯示「入選 0 檔」？**
A：正常。代表當天沒有標的同時符合「爆量 + 多頭訊號」。建議持幣觀望，別盲目追高。隔天或換個更激進門檻（`--min-score 40`）再試。

**Q：有些股票顯示 Yahoo 抓取失敗 / Not Found？**
A：部分次級股、OTC 代號在 Yahoo 沒有資料，會自動跳過並印 WARN，不影響其他標的。可從 universe.csv 拿掉這些代號。

**Q：週五下午跑，結果怪怪的？**
A：Yahoo 當日的棒子可能還沒完全更新（半日/盤後）。建議週一到週四跑最準；週五可等收盤稍久再跑。

**Q：進場價比現價還低？**
A：已自動處理——若當日已突破前日高，會改以「收盤 + 0.3%」作追單進場價，避免錯估。

**Q：v1 和 v2 要跑哪個？**
A：日常用 **v1**（`scanner.py` / `run.sh`）就夠了。想加籌碼面判斷、或做回溯驗證時才用 **v2**（`scanner_v2.py` / `backtest_v2.py`）。兩者技術面邏輯完全相同，v2 只是多疊一層三大法人買超。

## 九、⚠️ 重要限制（務必讀）

**籌碼面資料：部分可自動取得，部分仍需人工確認。**
- ✅ **T86 端點**（`twse.com.tw/rwd/zh/fund/T86`）已驗證可用——三大法人買賣超可回溯歷史日期，v2 已整合。
- ⚠️ **TWSE 官方 API**（`twse.com.tw/api/tw/s20,s23,s19,b465`、bfi82u）在本網域被反爬擋住（HTTP 403 / 反爬 HTML），無法自動。
- ⚠️ **外資持股前20名**（openapi.twse.com.tw）只給最新快照，無法回溯歷史日期。

因此工具會：
1. v2 表格中顯示「看多／看空風險」的籌碼提示。
2. 每檔結果後仍列出「需人工確認」的檢查清單（見下）。

**請務必人工核對：**
- 三大法人當日是否買超（證交所 bfi82u / s23）
- 買超第一名是不是「隔日沖大戶」（凱基台北、富邦建國、美林 → 防倒貨）
- 融券是否增加（券增價漲 → 可能有軋空行情）

## 十、風險提醒

本工具為**選股輔助工具，不是投資建議**。當沖高風險：
- 停損務必執行，勿「做多變留倉、留倉變套牢」。
- 黃金時段為開盤後 1 小時（09:00–10:00），動能最強。
- 乖離過大、開高走低的標的，寧可錯過別追高。
