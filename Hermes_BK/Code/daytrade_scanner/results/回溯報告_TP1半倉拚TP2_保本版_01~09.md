# 回溯報告：TP1 半倉停利 + 另一半拚 TP2（A 賣掉後 B 移到保本）

## 一、問題與設定

承接上一版「TP1 半倉 + 另一半拚 TP2」，本次把規則改進一歩：**當 A（TP1 那半倉）獲利了結後，B（拚 TP2 那半倉）的停損上移到「保本 = 進場價」**。

- **原版**：B 一直用原停損 sl → B 可能被洗出、拖累整筆。
- **本版**：A 一旦鎖利成功，B 最多平手（b=0），絕不虧 → **凡達 TP1 者皆為贏**。

回溯區間：**2026-01~09，195 個交易日，707 入選、485 觸發**。無滑點/手續費。

## 四、解讀

1. **保本版讓「達 TP1 的另一半」從「可能被洗掉」變成「最多平手」**。原版 47 筆「另一半收盤」縮到只有 8 筆——因為 B 移到保本後，只要沒破損就收盤了結（≈平手），不再拖后腿。

2. **勝率（僅TP/SL分母）從 54.7% 升到 59.2%**：原本「達TP1(另一半停損)」那 34 筆在保本版裡全部變成「保本平手」，這些子單不再算虧 → 明確出場者的勝率上升。

3. **累積獲利 +56 元/股（+2513 vs +2457）**：增幅不大但穩定，因為省掉了原本那 34 筆的停損拖累。

4. **停損洗出筆數不變（159）**：保本只保護「A 已鎖利」的子單；若 A 自己沒摸到 TP1 就被洗 → 整筆仍照原停損計算，不受影響。

## 五、誠實提醒

1. **仍是毛損益**。保本版平均獲利 +13.85 vs 停損均虧 -5.89（盈亏比 2.35），扣成本後抗力仍優於純 TP1/TP2，但固定每筆成本侵蝕小贏單的效應仍在。

2. **保本版的假設較理想**：A 在 TP1 成交後「瞬間」把 B 移到保本——實際交易有滑點、撤單時間差，B 未必能完美在進場價掛停損。本回溯用固定 entry 作保本，偏理想化（可能略高估）。

3. **勝率已接近 60%**：三種策略（TP1-only 42%、TP2-only 34%、半倉原版 55%）中最高且最穩，適合能處理雙倉操作的人。

## 六、結論

- **勝率：約 59~61%**（保本版僅 TP/SL 分母為三者最高）。
- **賺：累積 +2513 元/股（毛），平均每筆觸發 +5.18，盈亏比 2.35。**
- 相較原版（+2457 / 54.7%）小幅提升——**保本停損把「達 TP1 的另一半」從潛在拖累變成安全墊**，是三者中最穩健的執行方式。
