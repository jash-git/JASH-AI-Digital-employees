# 隔天當沖選股工具 — 月度回溯測試報告（2026 年 9 月）

**日期：** 2026-10-02　｜　**方法：** 用「截至各日收盤前」的資料跑選股，再對照「下一個交易日」實際行情
**資料來源：** Yahoo Finance chart API（OHLCV），全歷史每檔抓一次、記憶體切片逐日計算

## 一、測試設定

| 項目 | 內容 |

| 入選門檻 | 分數 ≥ 45、至少觸發 2 個訊號、成交量放大 |
| 進場規則 | 次日高點破進場價（entry），或開盤高於 entry |

| 停利 | TP1 = entry + R:R 1.5x；TP2 = entry + R:R 2.5x |
| 交易成本 | 每股往返 ~0.545%（佣金 0.1425% + 手續費 0.03% + 證券交易稅 0.1%，買賣各一次） |

## 四、誠實評析（多面向量化審視）

### ✅ 正面
1. **淨收益為正**：扣交易成本後仍 +180 元/股，平均每筆 +4 元。在「選入標日漲少跌多」的環境下做到正期望值，說明訊號有微弱邊際優勢。
2. **停損紀律有效**：24 笔被洗出但單筆虧損受控（上限 1.5%），沒有爆大虧。
3. **避開機制運作**：09-11、09-23~28 等日入選為 0 或未觸發，成功跳過不適合的交易日。

### ⚠️ 需要警惕
1. **勝率僅 31%**：45 筆中 24 筆停損（53%）。這是典型的「小贏大輸但總和為正」——靠少數大贏撐起淨利，結構上脆弱。
3. **收益高度集中**：**09-18（+202）與 09-21（+187）兩日合計貢獻 +389 元，佔全部毛利的 110%**。若剔除這兩天，其餘 47 筆反而微負（−35.4 元）。這表示「淨正收益」完全由極少數暴動日撐起，去掉後幾乎歸零甚至轉負——優勢很可能來自特定行情而非穩定可複製的模式。
3. **樣本太小**：n=45 筆、22 日，統計效力有限。無法排除這兩天是運氣（例如剛好遇到大單突破的暴動日）。
4. **籌碼面完全缺失**：文章最核心的「三大法人買超、券商分點、融券軋空」在本環境無法自動取得，工具只用到價量訊號——這可能正是勝率偏低的原因之一。

### 結論
> 工具在 9 月做到**淨正收益**，驗證了選股流程與風險控管的完整性；但優勢**高度依賴兩天的暴動行情**，勝率低、樣本小，尚無法斷言具有穩定可複製的邊際優勢。這是一個「有希望但未證實」的結果。

## 五、改進方向
1. **接上籌碼資料源**（TWSE API 或代理）：補足三大法人、券商分點、融券訊號——這是文章核心，也是提升勝率的最大機會。
2. **擴大回溯範圍**：多跑幾個月（含不同市場環境：多頭/空頭/震盪），確認那兩天不是運氣。
3. **微調停損/入選門檻**：53% 的停損洗出率偏高，可嘗試縮小進場窗口或提高分數門檻。
4. **加入大盤過濾**：大盤弱勢日整體降級（文章第五章強調「大盤跳空重挫則縮小部位」）。
