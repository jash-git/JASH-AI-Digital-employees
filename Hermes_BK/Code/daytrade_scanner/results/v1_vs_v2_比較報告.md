## 三、為什麼兩者完全相同？

`scanner_v2.py` 的籌碼層邏輯是「加分制」——它只在 stock **已經通過技術面門檻（score ≥ 45）**之後，才加上 `chumma_boost`（外資買超 +15、投信買超 +10、外資前20大 +8）。

```python
# scanner_v2.py scan_one_v2()
base = v1.scan_one(code, name, rows=rows)   # 技術面結果（或 None）
if base is None:
    return None                              # ← 未達門檻就直接回傳，籌碼層根本沒機會作用
result["score"] = min(100, base["score"] + boost)  # 只在已達門檻後才加分
```

**關鍵發現：** 我抽樣了 9 個日期 × 微星（2377，原檔誤標為「台積電」）驗證，`chumma_boost` 從未把任何 stock 從「未達門檻」推到「達門檻」。因為選股門檻是 `base_score ≥ 45`，而加分是在 `base_score` 之後才加——**如果技術面本身沒過線，籌碼再好看也進不了選股清單**。

換句話說：籌碼層目前只改變「入選股的最終分數」，不改變「哪些股入選」。所以回溯的觸發筆數、獲利、PnL 全部一致。

## 四、籌碼層的實際分布（雖未影響結果，但值得記錄）

| 指標 | 有加分 (320 筆) | 無加分 (165 筆) |
|------|------|------|
| 毛利 | +782.8 元 | +1,038.9 元 |

- **觸發交易中有籌碼加分者：320/485（66%）**，累計加分 5,195 分。
- **有法人資料的天數：181/195（93%）**——T86 每日更新，每週採樣不會漏掉可用資訊。

**觀察：** 有碼加分的 320 筆毛利 +782.8，反而低於無加分的 165 筆（+1,038.9）。這進一步佐證：目前的加分機制對選股結果沒有實質正面影響——被加分的股票平均表現甚至略差。加分只是「看起來多背書」，不改變勝率或期望值。

## 五、誠實結論

1. **v2 的籌碼層目前「未產生差異」**——因為它是加分制，只在已達技術面門檻後才作用，無法把低分股拉進清單。
2. v1 與 v2 在 1～9 月的回溯結果**完全相同**（485 筆觸發、46% 獲利、+1,821.8 元毛利）。
3. base rate 為 51%，表示「選股」本身只有微弱勝率優勢；籌碼加分也未改善勝率。

### 若要讓籌碼層真正發揮作用，建議方向（需與您確認後再改）：
- **(A) 把籌碼作為入選門檻**：例如「外資買超 + score ≥ 40」才入選，而非單純加分。
- **(B) 用籌碼做過濾**：在技術達標的 stock 中，剔除「外資大賣超」者（數據顯示外資賣超檔表現較差）。
- **(C) 調整加權**：目前 boost 上限 ~33 分（+20%），且與獲利負相關——可能需要反向操作或換訊號。

> ⚠️ 以上為誠實結果，未做任何數據美化。v1 `scanner.py` 邏輯維持不變。
