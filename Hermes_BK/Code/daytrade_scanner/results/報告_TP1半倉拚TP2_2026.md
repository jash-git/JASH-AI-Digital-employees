# 當沖選股績效報告：TP1 半倉停利 + 另一半拚 TP2

> 規則：**無滑點、無手續費**；嚴格遵守「開倉 + 停損 + TP1 先收一半 + 剩下一半跑 TP2」。
> 方法：`backtest_tp1half_tp2.py`（每檔拆兩個半倉，A 在 TP1 賣掉後 B 移到保本停損）。
> 資料窗口：TWSE 權威已定案日，next-bar 以此為 cap，排除 Yahoo 未定案「今日」棒。

## 二、策略怎麼運作（每檔 = 兩個半倉）

1. **進場觸發**：次日最高 ≥ 進場價，或開盤 > 進場價，才算進得去；否則錯過不交易。
2. **半倉 A（TP1）**：摸到 TP1 → 賣掉一半、鎖利；沒摸到又跌破停損 → 半倉停損；否則收盤了結。
3. **半倉 B（TP2）**：摸到 TP2 → 賣掉另一半；**若 A 已在 TP1 賣掉，B 的停損上移到「保本（進場价）」** → B 最多平手、絕不虧。
4. **關鍵效果**：**凡達 TP1 者皆為贏**（A 鎖半數利、B 保本），把勝率往上抬；同時留一半博 TP2 放大盈餘。

## 三、與單目標策略並比（同窗口 700 入選 / 486 觸發，可直接比較）

| 策略 | 勝率 | 累積毛 PnL（元/股） | 平均每筆 | 盈亏比 | 說明 |
|------|------|--------------------|---------|--------|------|
| **TP1 半倉 + 拚 TP2**（本策略） | **61.7%** | **+2,555.76** | **+5.26** | **2.31** | 兼顧鎖定与放大 |
| TP1-only（全部在 TP1 收手） | 46.1% | +700.58 | +1.44 | 1.89 | 快进快出，但達標率仅 34.6% |
| TP2-only（全部跑 TP2） | 44.2% | +1,583.46 | +3.26 | 3.40 | 大贏家多（平均 +22.6），但僅 25.1% 達 TP2 |

**解讀：**
- **勝率**：半倉制 61.7% ≫ 單押 TP1/TP2 的 44~46%。因為一半在 TP1 就锁定獲利，把半數交易变成贏家。
- **總報酬**：半倉制 +2,556 同時赢過 TP1-only（+701）與 TP2-only（+1,583）。它「拿走了 TP1-only 的高勝率，又保留了 TP2-only 的大段盈餘」。
- **盈亏比**：2.31 介於兩者之間——不是追求最大單筆盈餘，而是追求「穩定贏 + 穩賺」。

→ **結論：在相同選股名單下，TP1 半倉 + 拚 TP2 在勝率與總獲利兩項都最強。**

## 六、限制與注意事項

1. **費用影響巨大**：上面「毛」數字未扣費。按當沖**法定/監管最高費率**（買 0.1615%、賣 0.4615%）实测，至今（含今日實盤）累積毛利 +2,579.62 → **淨利 +1,037.68 元/股**（費吃掉約 60%），淨勝率 56.0%。**即使最保守估計仍賺**。重點：高價股（如大立光 ~3000 元）因單價高、費用絕對值大，是吃利罪魁禍首；實際當沖多數券商**免手續費**，真實净利會比 +1,037.68 更高。
2. **停損仍是唯一短板**：32.7% 的觸發筆停在損、贡献 −966 元/股。優化選股過濾（如剔除外資大賣超、波動過大）或动态停損，是提升淨利的首要方向。
3. **Yahoo 歷史會修正**：重跑可能上下浮動 ±10~20%（本次 1~9 vs 1~10-12 僅 0.6% 差，屬穩定）。
4. **進場價為次日預測**：遇跳空日失準（如前次 10-13 廣達開盤就偏離），停損易先被洗出。
