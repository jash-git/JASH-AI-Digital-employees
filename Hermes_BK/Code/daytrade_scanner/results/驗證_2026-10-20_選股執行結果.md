# 執行驗證：2026-10-19 選股報告 → 對照 2026-10-20 實際行情（TP1半倉拚TP2）

> 產生時間：2026-10-20（二）收盤後　｜　用「昨天報告（10-19）的 1 檔入選」＋「今天（10-20）真實 OHLC」回測
> 規則：**TP1 半倉停利 + 另一半拚 TP2**；A 在 TP1 賣掉後，B 的停損上移到「保本（進場价）」→ B 最多平手、絕不虧。
> 判定邏輯：沿用專案 `backtest_tp1half_tp2.py::evaluate()`（與月度回溯同模），保證一致。

## 一、判定規則（evaluate）

對「下一個交易日（10-20）」當日 OHLC 依序判定：

1. **能否進得去**：當日最高 ≥ 進場價，或開盤 > 進場價 → 才算觸發；否則「未觸發」（錯過、不交易）。
2. 若觸發，分兩個半倉（優先級 TP2 > TP1 > SL/收）：
   - **半倉 A（TP1）**：`h ≥ tp1` → 在 TP1 賣一半鎖利；`l ≤ sl` → 半倉停損；否則收盤了結。
   - **半倉 B（TP2）**：若 A 已在 TP1 賣掉 → B 停損移到**保本（=進場价）**，否則用原 sl。`h ≥ tp2` → 賣另一半；`l ≤ b_sl` → B 停損（保本時 = 平手）；否則收盤了結。
3. **毛 PnL = A + B**；淨 PnL = 毛 − 當沖費用（買 entry×0.1615%、賣各半倉出場價×0.4615%）。

> 注意：停損優先於停利判定——盘中先碰停損就算損，即使後來拉回也已是虧損。凡達 TP1 者皆為贏（A 鎖半數利、B 保本）。

## 四、誠實解讀與限制

1. **今日是「零觸發」的規避日**：昨日唯一入選（華碩）因開盤跳空偏低（962 vs 預測 1005）、全日最高僅 993，未達進場門檻 → 不交易、零損失。這是策略「開低/跳空不接」機制的正常運作。
2. **不改變累積數字**：此日毛 0.00、淨 0.00，故主報告 `報告_TP1半倉拚TP2_2026.md` 的累積仍為 **毛 +2,569.27、淨 +1,021.12 元/股、勝率 60.8%**（分母 513 筆觸發不變）；只把入選檔數從 753 推上 **754**。
3. **名單極窄是日際波動**：10-19 是繼 10-16（3 檔）、10-15（8 檔）之後更窄的「極窄名單」（僅 1 檔華碩），屬弱盤連日整理後的正常日際波動——達門檻的強勢股本身就少。名單窄不代表策略變差，只是當日機會少。
4. **外資逆風佐證**：昨日 v2 已標華碩「投信買超 +7.8 万股、但外資同日賣超 −103.4 万股」的「投信主導、外資逆風」；今日華碩開盘跳空走低，與外資拋壓方向一致（雖非策略觸發條件，但與昨日風險提示吻合）。
5. **費用提醒**：此日未成交故無費用。若執行，華硕 (~970–1005 元) 單價高，當沖費用絕對值大——這是本策略高價股的固有特性（參考 10-19 瑞昱淨 −16.50）。
6. **PnL 為每股**：已同時列出毛與淨；實際成交還受委託順序、盤中流動性影響。
