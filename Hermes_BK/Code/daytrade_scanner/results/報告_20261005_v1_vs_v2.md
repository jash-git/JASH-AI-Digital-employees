## 四、v2 真正帶來的差異（不只是加分）

1. **名單與排序不變**：7 檔完全相同，相對順序也未動。
2. **分數膨脹但門檻意義改變**：v1 最高 75 分 → v2 最高 90 分。加滿分的標的「多頭確認度」更高，
   可視為信心強化訊號，而非新的入選依據。
3. **風險揭露（最有價值）**：
   - **英業達（2356）**：v1 列「做多」，v2 因外資當日**賣超 494.9 萬股**而標註「看空風險」。
     技術面過關但主力在出貨——這是 v1 完全看不到的警訊。
   - **日月光（3711）**：兩版都列「觀望(開高走低)」，v2 再補外資買超 308 萬股，形成「技術乖離 + 籌碼看多」的背離，需留意。
4. **做空估值**：v2 對外資賣標的（英業達）額外提供 short_entry/short_sl/short_tp 估值表，v1 沒有。

## 五、使用建議

- **選股名單**：以 v1 為準繩（技術面硬門檻），v2 不改變入選邏輯。
- **進場決策**：用 v2——它把「主力是否同向」補進來。英業達雖過技術線，但外資大賣超，
  實務上應降級或剔除，这正是 v2 的價值。
- **分數別當絕對標準**：v2 的 90 分不是比 v1 的 75 分「強兩倍」，而是同一筆技術訊號 + 外資買超加分。
