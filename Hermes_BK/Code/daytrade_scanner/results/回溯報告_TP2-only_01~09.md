# 回溯報告：TP2-only 規則（開倉 + 停損 + TP2 停利，無滑點）

## 一、問題與設定

用戶提問：**「不考慮滑點、嚴格遵守開倉 + 停損 + TP2 停利規則，勝率多少、賺多少？」**

沿用 `backtest_tp1_only.py`（已泛化為 `--tp {tp1,tp2}`），本次用 `--tp tp2`。
回溯區間：**2026-01~09，195 個交易日，707 入選、485 觸發**。

## 二、核心結果（TP2-only）

### 出場分佈（485 筆觸發中）
| 結果 | 筆數 | 占比 |
|------|------|------|
| **達 TP2（獲利了結）** | 120 | **24.7%** |
| **停損洗出** | 231 | **47.6%** |
| 收盤未達任一目標 | 134 | 27.6% |

### 勝率（兩種算法）
| 定義 | 獲利 / 分母 | 勝率 |
|------|------------|------|
| 分母 = 全部觸發（含收盤了結） | 216 / 485 | **44.5%** |
| 分母 = 僅 SL/TP2 明確出場者 | 120 / 351 | **34.2%** |

### 損益（元/股，毛、無滑點）
| 項目 | 數值 |
|------|------|
| **累積 PnL** | **+1602.34 元/股** |
| → 達 TP2 貢獻 | +2751.52 元/股 |
| → 停損虧損 | -1528.16 元/股 |
| → 收盤了結 | +378.98 元/股 |
| 平均每筆觸發 PnL | **+3.30 元/股** |
| 平均獲利（達TP2） | +22.93 元/股 |
| 平均虧損（停損） | -6.62 元/股 |
| **盈亏比** | **3.47** |

## 三、TP1 vs TP2 直接對照（同一批 485 筆觸發）

| 指標 | TP1-only | TP2-only |
|------|----------|----------|
| 達目標筆數 | 167（34.4%） | 120（24.7%） |
| 停損筆數 | 231（47.6%） | 231（47.6%） |
| 收盤未達 | 87（17.9%） | 134（27.6%） |
| **勝率（分母=全部觸發）** | **46.4%** | **44.5%** |
| **勝率（分母=僅SL/TP）** | **42.0%** | **34.2%** |
| 累積 PnL（毛） | +721.14 | **+1602.34** |
| 平均每筆觸發 | +1.49 | **+3.30** |
| 平均獲利（達目標） | +12.65 | +22.93 |
| 盈亏比 | 1.91 | **3.47** |

## 四、解讀

1. **TP2 累積獲利幾乎是 TP1 的 2.2 倍（+1602 vs +721）**，但勝率略低、且只有 1/4 達標。
   - 關鍵在**盈亏比**：TP2 平均每次獲利 +22.93，是停損均虧 -6.62 的 **3.47 倍**。
   - TP1 平均每次只賺 +12.65（盈亏比 1.91），雖然命中率較高但單筆利潤薄。

2. **「少賺」的部分不是虧損，是機會成本。**
   TP2 有 134 筆（27.6%）收盤沒摸到 TP2——這些單子若停在 TP1 本可獲利了結，卻因為只設 TP2 而收盤了結（其中不少是微利或平手）。換句話說：**TP2 用「放棄部分小賺」換取「更大單筆利潤」**。

3. **停損筆數完全相同（231）**——無論目標遠近，虧錢的單子數量不變。差異全在獲利端：TP2 把獲利的天花板拉高了。

## 五、誠實提醒（重要）

1. **仍是毛損益，未扣成本。** 以平均每筆 +3.30 元/股、停損均虧 -6.62 元/股看，固定每筆成本仍侵蝕小贏單。但 TP2 平均獲利較厚（+22.93），**扣成本後的相對抗力比 TP1 強**。

2. **勝率只有 34~44%**——近六到七成交易不賺錢或平手，必須靠嚴格停損 + 高盈亏比維持正期望。心理壓力大，不能扛單。

3. **「未觸發」的 31%（進場單沒摸到）仍是隱藏成本**，TP2 與 TP1 相同。

## 六、結論

- **勝率：約 34~45%**（取決於算法），比 TP1 略低。
- **賺：累積 +1602 元/股（毛），平均每筆觸發 +3.30 元/股，盈亏比 3.47。**
- 策略是**更低勝率、更高盈亏比**的正期望系統——用「放棄小單」換「大單利潤」。若你的執行力能扛住低勝率並嚴格停損，TP2 的長期期望值明顯高於 TP1。
