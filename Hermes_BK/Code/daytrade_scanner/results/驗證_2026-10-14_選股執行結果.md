# 執行驗證：2026-10-13 選股 → 對照 2026-10-14 實際行情（TP1半倉拚TP2）

> 產生時間：2026-10-14（三）收盤後　｜　用「昨天報告（10-13）的 8 檔入選」＋「今天（10-14）真實 OHLC」回測
> 規則：**TP1 半倉停利 + 另一半拚 TP2**；A 在 TP1 賣掉後，B 的停損上移到「保本（進場价）」→ B 最多平手、絕不虧。
> 判定邏輯：沿用專案 `backtest_tp1half_tp2.py::evaluate()`（與月度回溯同模），保證一致。

## 一、判定規則（evaluate）

對「下一個交易日（10-14）」當日 OHLC 依序判定：

1. **能否進得去**：當日最高 ≥ 進場價，或開盤 > 進場價 → 才算觸發；否則「未觸發」（錯過、不交易）。
2. 若觸發，分兩個半倉（優先級 TP2 > TP1 > SL/收）：
   - **半倉 A（TP1）**：`h ≥ tp1` → 在 TP1 賣一半鎖利；`l ≤ sl` → 半倉停損；否則收盤了結。
   - **半倉 B（TP2）**：若 A 已在 TP1 賣掉 → B 停損移到**保本（=進場价）**，否則用原 sl。`h ≥ tp2` → 賣另一半；`l ≤ b_sl` → B 停損（保本時 = 平手）；否則收盤了結。
3. **毛 PnL = A + B**；淨 PnL = 毛 − 當沖費用（買 entry×0.1615%、賣各半倉出場價×0.4615%）。

> 注意：停損優先於停利判定——盘中先碰停損就算損，即使後來拉回也已是虧損。凡達 TP1 者皆為贏（A 鎖半數利、B 保本）。

## 四、誠實解讀與限制

1. **這次贏，但贏得很集中**：6 筆毛 +14.35 中，瑞昱+聯詠兩檔就贡献 +14.3（99%）。這兩檔正是「達 TP1 → A 鎖利 + B 保本」設計的直接體現——與回溯「達 TP1 合計 50% 且全獲利/平手」的支柱完全吻合。
2. **停損仍是唯一短板**：和碩、仁寶兩档停損贡献 −2.0（毛），各亏小錢。這正是回溯那 32.7%「唯一短板」的實盤翻版——若能把停損率壓低，總報酬會再往上跳。
3. **未觸發是規則保護而非錯過**：台積電、台光電皆大幅低開，從未摸到預測進場價 → 不交易、零損失。這印證報告第六點第 4 條「進場價為隔日預測，跳空日失準」——模型在跳空日的開盤預測偏多，但規則以「未觸發」處理，沒讓它接刀。
4. **勝率 66.7%（4/6）高於回溯基準 61%**：樣本僅一天 8 檔、且含 2 檔未觸發，屬小樣本方向性驗證，不代表長期；但「達 TP1 皆贏、停損小亏、跳空不接」三點與策略邏輯一致。
5. **費用影響**：6 筆毛 +14.35 → 淨 +3.61，當沖最高費吃掉約 24%（比回溯 1~10-12 的 59% 低很多——本次高價股成交少、且兩檔未交易）。遠傳更是毛利 0.20 < 費用 0.67，未扣費微利、扣費轉負；實際多數券商當沖免手續費，真實净利會更高。
6. **PnL 為毛/淨額、每股**：已同時列出毛與淨，供比較；實際成交還受委託順序、盤中流動性影響。

## 五、結論

按昨天報告執行：**6 筆觸發獲利 4、虧損 2（勝率 66.7%），累積毛 +14.35、淨 +3.61 元/股**；另 2 檔（台積電、台光電）因開盤跳空未觸發、不交易。

方向與策略設計完全一致——半倉制把「達 TP1」鎖成贏家（瑞昱+聯詠），停損只吃小亏（和碩、仁寶），跳空日靠「未觸發」規避（台積電、台光電）。这是一次性小樣本驗證，不影響系統層級回溯表現（月度回溯另計），但再次確認：**進場/開盤預測在跳空日風險高，停損易先被洗**——與 10-13 遠傳案例同構。
