# 回溯報告：TP1-only 規則（開倉 + 停損 + TP1 停利，無滑點）

## 一、問題與設定

用戶提問：**「不考慮滑點、嚴格遵守開倉 + 停損 + TP1 停利規則，勝率多少、賺多少？」**

因此建立 `backtest_tp1_only.py`，與既有 `backtest_v2.py` 的關鍵差異：

| 項目 | backtest_v2（原版） | backtest_tp1_only（本次） |
|------|--------------------|--------------------------|
| 出場目標 | TP1 **和** TP2 | **只 TP1**（用戶指定） |
| 收盤未達目標 | 以收盤了結 | 以收盤了結（當沖無法過夜） |
| 滑點/手續費 | 不扣 | **不扣**（用戶指定無滑點） |
| 籌碼層 | v2 加分制 | v1（加分不改 entry/sl/tp，結果相同） |

回溯區間：**2026-01~09，195 個交易日，29 檔 universe**。

## 二、核心結果

### 入選與觸發
| 項目 | 數值 |
|------|------|
| 全部入選筆數 | **707** |
| 實際觸發進場 | **485 筆（69%）** |
| 未觸發（錯過） | 222 筆（31%） |

### 出場分佈（485 筆觸發中）
| 結果 | 筆數 | 占比 |
|------|------|------|
| **達 TP1（獲利了結）** | 167 | **34.4%** |
| **停損洗出** | 231 | **47.6%** |
| 收盤未達任一目標 | 87 | 17.9% |

### 勝率（兩種算法）
| 定義 | 獲利 / 分母 | 勝率 |
|------|------------|------|
| 分母 = 全部觸發（含收盤了結） | 225 / 485 | **46.4%** |
| 分母 = 僅 SL/TP1 明確出場者 | 167 / 398 | **42.0%** |

> 解讀：若把「收盤未達目標」也算進勝率分母，勝率約 **46%**；若只看有明確停損或達 TP1 的交易（最純粹的 SL/TP1 對決），勝率約 **42%**。兩者都落在「略低於五成」的水準——這策略靠的是**盈亏比**而非高勝率賺錢。

### 損益（元/股，毛、無滑點）
| 項目 | 數值 |
|------|------|
| **累積 PnL** | **+721.14 元/股** |
| → 達 TP1 貢獻 | +2111.84 元/股 |
| → 停損虧損 | -1528.16 元/股 |
| → 收盤了結 | +137.46 元/股 |
| 平均每筆觸發 PnL | +1.49 元/股 |
| 平均獲利（達TP1） | +12.65 元/股 |
| 平均虧損（停損） | -6.62 元/股 |
| **盈亏比** | **1.91** |

## 三、與原版回溯對照

| 指標 | backtest_v2（TP1+TP2） | TP1-only（本次） |
|------|------------------------|------------------|
| 入選筆數 | 546 | 707 |
| 觸發進場 | 375（69%） | 485（69%） |
| 勝率 | ~45% | **42~46%** |
| 淨利（扣成本） | +604.8 元 | **+721.14 元（毛）** |

**關鍵發現：只停在 TP1 反而比持有到 TP2 更賺。** 原因——很多達不到 TP2 的單子，若硬等 TP2 會把利潤還回去；提前在 TP1 收手能鎖利。TP1-only 累積 +721 vs 原版 +604.8（毛），多出約 19%。

## 四、誠實提醒（重要）

1. **這是「毛」損益，未扣任何成本。** 實際當沖有：
   - 證券交易稅（賣出 0.1%）、手續費（各約 0.145%，最低 20 元）、
   - 若走零手續費券商仍有最小收費。以平均每筆獲利 +1.49 元/股、停損均虧 -6.62 元/股來看，**每筆固定成本（約 20~40 元/張）對小贏單的侵蝕極大**。
   - **換算成「扣成本後」很可能接近打平甚至微負**——這是本結果最需要謹慎解讀的地方。

2. **勝率偏低（42~46%）**，靠 1.91 倍的盈亏比撐出正期望。這代表心理壓力大——近半數交易虧錢，必須嚴格執行停損，不能扛單。

3. **「未觸發」的 31% 也是成本**：進場單設在突破位（前日高），沒摸到就錯過。這部分雖不算虧損，但錯失了無風險的資金機會成本。

## 五、結論

- **勝率：約 42~46%**（取決於是否把「收盤未達目標」算進分母）。
- **賺：累積 +721 元/股（毛），平均每筆觸發 +1.49 元/股，盈亏比 1.91。**
- 策略是**低勝率、高盈亏比**的正期望系統，但**扣成本後需重新驗證**——目前毛數看起來不錯，實際淨利可能大幅縮水。
