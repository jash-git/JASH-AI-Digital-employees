## 六、誠實評析（多面向量化審視）

### ✅ 正面
1. **淨收益為正**：扣交易成本後 +1,547.7 元/股，在 base rate 近乎 50/50 的環境下做到正期望值。
2. **勝率明顯提升**：從 9 月的 31% 升到 48%，樣本越大越接近「可複製」的邊際優勢。
3. **停損紀律有效**：203 筆被洗出但單筆受控（上限 1.5%），沒有爆大虧。

### ⚠️ 需要警惕
1. **收益高度集中且集中在特定個股**：**最大單筆贏家 Top-5 以創意（3443）和大立光（3008）為主**；從累計毛利看，**聯發科、台積電、大立光三檔半導體就佔了大部分利潤**。這表示優勢很可能來自這幾檔高 beta 半導體的單日暴動行情，而非普適模式——換成其他標的未必有同樣表現。
2. **下半年轉負**：7～8 月毛利 −97.1 元，幾乎吃掉上半年利潤的一半。勝率從 52% 掉到 29%，訊號在特定市場環境失效。
3. **單股巨虧**：**台光電（2383）全期 −191.8 元**（僅 5 筆），是最大拖累——顯示停損對少數標的完全無效，可能進場點過晚或該檔波動異常。
4. **停損洗出率仍高**：47%（203/432），結構上仍是「小贏大輸但總和為正」。
5. **樣本雖增但仍有限**：n=432 筆、8 個月，無法排除個股暴動日是運氣。

### 結論
> 擴大到 1～8 月後，勝率從 31% 升到 48%，淨利仍為正（+1,547.7），顯示訊號有**微弱但真實的邊際優勢**。但優勢**高度依賴特定個股（聯發科、台積電、大立光）的暴動行情**，且下半年轉負——這表示工具在「多頭/震盪日」有效，在「空頭/高波動日」可能失效。這是一個「有條件成立」的結果：環境好時有用，環境差時要停手。

## 七、改進方向
1. **接上籌碼資料源**（TWSE API 或代理）：補足三大法人、券商分點、融券軋空——這是文章核心，也是提升勝率的最大機會。
2. **加入大盤/個股環境過濾**：7～8 月轉負可能與大盤弱勢有關；可考慮在特定技術指標（如大盤跌破 20 日線）時降級或停跑。
3. **微調停損/入選門檻**：47% 的停损洗出率偏高，可嘗試縮小進場窗口或提高分數門檻。
4. **剔除表現異常個股**：台光電（2383）全期 −191.8 元，需檢討是否該檔根本不適合當沖策略。
