## 三、逐檔解讀（為什麼輸贏這樣分）

1. **鴻海 +3.0%（唯一大勝）**：進場觸發 254.8，但 10/06 直接開在 263、高見 266.5。
   只有「掛在 254.8 等突破」才能吃到 TP2 的 +3%；追單者開盤就站在 263，反而沒湯喝。
2. **大立光 +2.2%**：進場 6750、高見 6915 碰得到 TP1（6901.6）。開盤 6800 追也能吃到 +1.5%，屬少數「技術面與當日走勢一致」的標的。
3. **光寶 / 華碩 −1.5%**：進場觸發後当日低見底、直接打停損。華碩更慘，開在 995（低於進場 998），一開盤就虧。
4. **英業達 −1.5%（v2 提前示警）**：報告 v2 已標「外資賣超 495 萬股、看空風險」——當天果然低開走低打停損。**若聽 v2 的勸退，這筆可省 −1.5%**。
5. **日月光 −1.5%**：v2 雖標外資買超，但技術面乖離（觀望），當日低見 733 打停損。
6. **微星 −0.3%（險勝）**：全日沒碰停損也沒達 TP，收盤平出，幾乎白跑。

## 四、結論與檢討

- **整體：小虧**。Scenario A 淨 −1.6%（7 檔等資），Scenario B 更差約 −2.5%。
- **勝率低但風險對稱**：4 虧 / 2 盈 / 1 平，虧的都是固定 −1.5%（停損發揮作用），盈的靠鴻海單筆 +3% 拉回。若沒有鴻海這筆大勝，整體會更亏。
- **v2 的真實價值在此驗證中浮現**：英業達 v2 提前標「外資賣超、看空風險」，當天實測 −1.5%。**若嚴格執行 v2 的籌碼警訊剔除英業達，淨損可從 −1.6% 收窄至約 −0.1%**。這印證了上一份報告的判斷——籌碼層最大的貢獻不是加分，而是「避開主力出貨股」。
- **進場執行的脆弱性**：鴻海 +3% 高度依賴「卡在觸發價成交」；實際跳空下，追單者拿不到這個獲利。選股邏輯 OK，但執行面（如何捕捉突破觸發、避免高開追單）是下一個要優化的環節。
