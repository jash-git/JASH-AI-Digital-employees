# 隔天開盤當沖選股掃描器 (Next-day-open day-trade scanner)

把 Gemini 文章《**隔天開盤當沖選股策略與技巧**》的四大指標，轉成「本環境實際能自動取得」的可量化訊號。每日收盤後執行 → 列出隔日適合開盤當沖的標的 + 進場/停利/停損/方向估值表。

## 文章觀點交叉比對（原文 vs. 本工具實現）

| 文章四大金剛 | 原文條件 | 本工具是否可自動化 | 說明 |
|---|---|---|---|
| 1. 成交量與流動性 | 日量≥5000張、成交≥3-5億、量≥1.5×5日均量、週轉率8-15% | ✅ **部分** | 用 Yahoo OHLCV 算「量/5日均量」+ 最小成交張數。週轉率需股本（Yahoo chart API 未直接提供，改以成交量門檻代理）。 |
| 2. 籌碼集中度 | 外資/投信大買、主力集中、資券變化、軋空 | ✅ **部分（v2）** | v1 無法自動（TWSE s20/s23 被反爬擋）。**v2 已整合 T86 端點**——三大法人買賣超可回溯歷史日期，作為選股籌碼加分。外資持股前20名、融券僅給最新快照或需人工。 |
| 3. 價量與形態 | 創波段新高、收在最高、強勢鎖漲停 | ✅ **部分** | 用 Yahoo OHLCV 算「創波段新高」「收/高比」「站上 MA20」「多頭排列」。漲停委買單量需 TWSE，無法自動。 |
| 4. 消息面與題材 | 營收利多、熱門產業焦點 | ❌ **不適用** | 屬新聞/情緒面，非結構化數據可自動化（除非接新聞 API）。 |

**風險控管（文章第五章）**：✅ 已實現 — 停損 0.8-1.5%、R:R 1.5x/2.5x、乖離過大降級「觀望」、黃金時段提醒。

## 資料來源（本環境已驗證）
- ✅ **Yahoo Finance chart API**：OHLCV，可靠、可批次抓取（`v8/finance/chart/<CODE>.TW?range=3mo&interval=1d`）。
- ✅ **T86 三大法人買賣超**（`twse.com.tw/rwd/zh/fund/T86?date=YYYYMMDD&selectType=ALL&response=json`）：免 key、**可回溯歷史日期**——v2 籌碼層主力來源。
- ⚠️ **外資持股前20名**（openapi.twse.com.tw/v1/fund/MI_QFIIS_sort_20）：只給最新快照，無法回溯。
- ❌ **TWSE 官方 API**（twse.com.tw/api/tw/s20,s23,s19,b465、bfi82u）：回傳反爬 HTML / HTTP 403，無法自動。
- ⚠️ HiStock、wantgoo/goodinfo 等第三方域名在本環境 DNS 解析失敗或需登入。

## 使用方式
```bash
cd /home/vblinux/daytrade_scanner

# v1：日常選股（純技術面）
bash run.sh                 # 預設 top12, min-score45
bash run.sh --top 8         # 自訂筆數
python3 scanner.py --help   # 完整選項

# v2：加籌碼層 + 回溯測試
python3 scanner_v2.py --top 10 --min-score 45     # 即時選股（含三大法人）
python3 backtest_v2.py --start-month 1 --end-month 9   # 1～9月回溯
```

### 選項
- `--universe PATH`：標的清單 CSV（代號,名稱），預設 `universe.csv`。
- `--top N`：輸出分數最高的 N 檔（預設 12）。
- `--min-score N`：最低入選分數（預設 45）。
- `--out-csv PATH`：額外輸出 CSV。

## 評分邏輯（0-100）
| 訊號 | 權重 | 觸發條件 |
|---|---|---|
| 成交量倍增 | 25 | 今日量 ≥ 1.3× 近5日均量 |
| 創波段新高 | 25 | 收盤 ≥ 近40日最高（99.5%） |
| 強勢收最高 | 15 | close/high ≥ 0.97 |
| 均線多頭排列 | 15 | MA5 > MA10 > MA20 |
| 站上 MA20 | 10 | close ≥ MA20（多頭區） |
| 波動度適中 | 10 | ATR/price ∈ [1.2%, 4.5%] |

**入選門檻**：至少觸發 2 個訊號，且成交量有放大。乖離過大（close/MA20 > 1.10）→ 降級「觀望(開高走低風險)」。

## 進場/停損/停利估算
- **進場**：突破策略用「前日高」；若當日已收在前日高之上（突破已發生或今日棒未更新），改以「收盤+0.3%」追單。
- **停損**：max(價格 0.8%, ATR×0.6)，上限 1.5%（文章建議）。
- **TP1/TP2**：進場 ± R:R 1.5x / 2.5x。

## 接上籌碼資料源（v2 已整合）
v2 已用 T86 端點整合三大法人買賣超（可回溯歷史日期），無需手動接 hook。若你想換成其他資料源，改 `scanner_v2.py` 的 `fetch_chumma_cache()` 即可，選股與估值邏輯不變。

> ⚠️ 外資持股前20名、融券餘額等端點僅給最新快照或需人工查，尚無法回溯歷史日期。

## 重要提醒
- ⚠️ **本工具為選股輔助，非投資建議**。當沖高風險，停損務必執行。
- ⚠️ **籌碼面仍需部分人工確認**：外資持股前20名分點、隔日沖大戶、融券變化——這些 v2 尚無法自動回溯，需人工查（bfi82u / s23）。v2 已自動整合三大法人買賣超。
- 收盤後（15:00-18:00）執行最佳；Yahoo 今日棒在週五下午可能未完全更新。
